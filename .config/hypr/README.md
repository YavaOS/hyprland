Hyprland loads `hyprland.lua`. All Lua configuration now lives in this directory, with bindings in `bindings/`, application rules in `apps/`, and toggle modules in `toggles/`. The entry point loads each module once. Local settings and bindings replace their former default definitions.

Workspaces 1–9 stay on HDMI-A-1 and workspace 10 on eDP-1, with the dropdown terminal on `special:scratchpad`.
